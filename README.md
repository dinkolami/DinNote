# DinNote

**Daripada catatan kepada khazanah ilmu.**

Aplikasi Android untuk catatan peribadi dan pengurusan khazanah ilmu, dengan sokongan bahasa Arab dan Melayu.

## Prinsip pembangunan

- Offline First, Account Optional: penggunaan asas tanpa pendaftaran atau log masuk wajib.
- Utamakan kestabilan, privasi dan integriti data pengguna.
- Kekalkan pengalaman penyuntingan dan pembacaan yang konsisten.
- Sokong paparan potret, landskap dan peranti boleh lipat.
- Utamakan prestasi dan kesederhanaan sebelum menambah fungsi.

## Perlindungan data

Nota peribadi disimpan dalam pangkalan data tempatan. Pemasangan APK sahaja pada peranti baharu tidak memindahkan nota peribadi secara automatik. Sandaran dan pemulihan data perlu dikekalkan sebagai keutamaan pembangunan.

Kemas kini aplikasi hendaklah mengekalkan identiti pakej dan kunci tandatangan yang sama serta meningkatkan versionCode.

## Hala tuju

PIN, biometrik dan penyelarasan awan merupakan pilihan pembangunan, bukan syarat penggunaan aplikasi. Akaun awan, jika diperkenalkan, hendaklah bersifat pilihan.
