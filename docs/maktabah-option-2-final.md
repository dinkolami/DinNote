# Maktabah DinNote — approved option 2

Approved by user on 18 November 2026.

## Book-card layout

- Preserve emerald green, cream and subtle gold visual language.
- Use smaller book-cover icons, with shorter, denser cards and reduced whitespace.
- Display the Malay/Latin book title and metadata in the left/center text region.
- Replace the right-side **Baca Buku** button with the actual Arabic book title, right-aligned and rendered RTL.
- Place the **Offline** status directly underneath that Arabic title on the right.
- Do not duplicate the Offline badge on the left.
- Keep the whole book card tappable to open the book, with accessible touch target.
- Use genuine book metadata and preserve Arabic harakat where available; support wrapping without clipping.
- Respect Android navigation bars, foldable devices and landscape mode.

Examples: الأربعون النووية; المجموع شرح المهذب; سورة الفاتحة.

This commit documents the approved design. Application UI source changes are still required before the APK reflects this layout.
