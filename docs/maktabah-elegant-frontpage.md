# DinNote Maktabah — elegant frontpage concept

Approved visual direction (18 November 2026): refined emerald green, cream and restrained gold accents.

## Frontpage implementation brief

- Elegant green-and-gold DinNote header with Islamic geometric pattern and subtle mosque silhouette; keep the header compact to maximize reading space.
- Preserve existing Kalimah & Hikmah / Maktabah Kitab tabs, category selector and bottom navigation.
- Keep book-cover thumbnails and compact card layout; use small gold accents, readable Arabic RTL titles, Malay descriptions and offline status.
- Position Arabic labels close to book metadata rather than leaving large blank spaces.
- Ensure cards, text and navigation scale correctly on narrow screens, landscape and foldable Android devices; respect system navigation insets.
- Avoid duplicating large hero headers in the actual implementation. Favor one restrained banner, accessible touch targets and fast rendering.

This commit records the approved design direction only; it does not claim the Android UI code or assets have been updated.
