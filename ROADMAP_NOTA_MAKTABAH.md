# Pelan Induk DinNote — Nota dan Maktabah

Dokumen ini menyimpan semua 20 cadangan supaya cadangan yang belum dipilih tidak hilang. Status awal **Menunggu** bermaksud belum disahkan siap; jangan anggap ciri tiada atau belum wujud tanpa audit kod.

## Nota
- [ ] 1. Kategori fleksibel — tambah, ubah nama, susun dan padam kategori.
- [ ] 2. Editor Arab dan Rumi — RTL/LTR, sokongan baris Arab.
- [ ] 3. Autosave pintar — simpan ketika menaip dan keluar editor.
- [ ] 4. Format tulisan — bold, italic, underline, saiz dan warna.
- [ ] 5. Nota disemat (pin) — nota penting di atas.
- [ ] 6. Carian pintar — tajuk, isi dan kategori.
- [ ] 7. Checklist — tandakan tugasan selesai.
- [ ] 8. Nota panjang — bacaan skrin penuh.
- [ ] 9. Tong sampah — pulihkan nota terpadam.
- [ ] 10. Backup dan restore — sandaran dalam folder DinNote telefon.

## Maktabah
- [ ] 11. Kategori kitab sendiri — cipta dan urus kategori.
- [ ] 12. Subkategori bertingkat — kategori > subkategori > kitab.
- [ ] 13. Tambah kitab sendiri — nama, pengarang, kandungan.
- [ ] 14. Bab dan fasal — struktur kitab.
- [ ] 15. Editor kitab Arab/Rumi — Arab berbaris, terjemahan, huraian.
- [ ] 16. Penanda halaman — sambung bacaan terakhir.
- [ ] 17. Carian seluruh kitab — Arab dan Melayu.
- [ ] 18. Nota peribadi pada kitab — tanpa mengubah teks asal.
- [ ] 19. Salin dan kongsi petikan — teks Arab dan terjemahan.
- [ ] 20. Import dan eksport kitab — fail teks.

## Proses pelaksanaan
1. Pengguna pilih beberapa nombor dahulu; selebihnya kekal dalam senarai.
2. Audit kod sedia ada sebelum perubahan; tandakan **Dalam proses** semasa kerja bermula.
3. Commit kod, semak GitHub Actions dan uji APK; hanya tandakan **Selesai** apabila telah disahkan.
4. Kekalkan reka bentuk asal yang diluluskan: home dua menu Nota dan Maktabah, logo/header, warna silver lembut, status bar dan navigation bar Android.
5. Paparan Fold6: tertutup 5 nota satu kolum; terbuka 5 kiri + 5 kanan. Jangan ubah tanpa persetujuan.
6. Kemas kini fail ini pada setiap peringkat; jangan padam cadangan berbaki.
